# Jeu 95 Online - V5 mobile

Cette version garde le design mais corrige l’utilisation sur téléphone :
- interface adaptée mobile,
- champ "Score annoncé" accessible,
- clavier numérique,
- cartes plus faciles à sélectionner au doigt,
- bouton Jouer visible,
- meilleure lisibilité quand le clavier du téléphone s’ouvre.
